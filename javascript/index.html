JavaScript errors

  • [plugin:vite:import-analysis] Failed to resolve importVite could not map an import path to a file or installed package. Usually a typo or wrong case in the path, a missing npm package, or a path alias (like @/) defined in tsconfig but not in vite.config.
  • Each child in a list should have a unique "key" prop.You rendered an array of elements in React (usually with .map) without giving each element a stable, unique key prop, or two elements share the same key.
  • error TS1286: ESM syntax is not allowed in a CommonJS module when 'verbatimModuleSyntax' is enabled.With verbatimModuleSyntax on, TypeScript emits imports exactly as written, so it refuses import/export in files it treats as CommonJS (no "type": "module" in package.json, or a .cts file). Make the file ESM or turn the option off.
  • error TS1361: cannot be used as a value because it was imported using 'import type'.You imported something with import type (which is erased at compile time) but then used it at runtime, e.g. with new, instanceof, as an enum value or as a function. Import it as a normal value instead.
  • error TS2304: Cannot find nameTypeScript doesn't know a global name: either a missing type package (@types/node, @types/jest), a missing lib in tsconfig (dom, es2020), a tsconfig 'types' list that excludes it, or a plain typo/missing import.
  • Error: certificate has expired (CERT_HAS_EXPIRED)Node's TLS check found a certificate in the server's chain whose validity period has ended, or your system clock is wrong. Common causes: a wrong date, a server with an expired cert, an outdated CA store or an old intercepting proxy cert.
  • Expected 1 arguments, but got 0. ts(2554)You called a function, method or constructor with a different number of arguments than its TypeScript signature declares. Either pass the right arguments or change the signature (optional, default or rest parameters).
  • Hydration failed because the initial UI does not match what was rendered on the serverIn Next.js (or any React SSR), the HTML React renders in the browser on first load differs from the HTML the server sent. Caused by browser-only values (window, Date, Math.random, localStorage) used during render, or invalid HTML nesting.
  • Invalid hook call. Hooks can only be called inside of the body of a function component.A React hook (useState, useEffect, useContext, ...) ran outside a function component's render, or the app has two copies of React. The message lists the three possible reasons.
  • Maximum update depth exceededA React effect or lifecycle method updates state, which re-renders, which runs the effect again, forever. Usually a useEffect without a dependency array, or a dependency that is a new object/array/function on every render.
  • Module not found: Error: Can't resolvewebpack (used by Create React App, Next.js, Angular, Storybook...) couldn't find a file or package you imported. The path or case is wrong, the package isn't installed, an alias isn't configured, or it's a Node core module that webpack 5 no longer polyfills.
  • Object is possibly 'undefined'. ts(2532)TypeScript strict null checks found a value whose type includes undefined (or null) being used as if it were always defined. Narrow the type, provide a default, or fix the type.
  • Objects are not valid as a React childYou tried to render a plain object, Date, or Promise directly inside JSX. React can only render strings, numbers, elements, arrays of those, null and booleans.
  • Property 'x' does not exist on type 'Y'TypeScript only lets you access properties it knows exist on a value's type. The type is too narrow (often `{}` or a union), the property is missing from your interface, or a DOM/global type needs to be narrowed or extended.
  • React Hook useEffect has a missing dependencyThe ESLint rule react-hooks/exhaustive-deps found a value used inside useEffect (or useCallback/useMemo) that isn't listed in the dependency array, which can make the effect run with stale values.
  • ReferenceError: require is not definedrequire() only exists in CommonJS. In ES modules and browsers, use import, or create require with createRequire.
  • ReferenceError: x is not definedYou used a variable or function name that doesn't exist in the current scope. Typo, missing import, script loaded in the wrong order, browser-only global used in Node (or vice versa), or a variable defined inside another block.
  • SyntaxError: Cannot use import statement outside a moduleNode (or a test runner) is treating your file as CommonJS. Set "type": "module", use .mjs, or switch to require().
  • SyntaxError: The requested module does not provide an export namedAn ES module import asked for a name the target module doesn't export: a default vs named mismatch, a typo, a type-only export, or a CommonJS package whose exports can't be detected as named ESM exports.
  • SyntaxError: Unexpected token '<', "<!DOCTYPE "... is not valid JSONYou called response.json() but the server returned HTML (an error page, a 404, or your app's index.html). Check the URL and the response status.
  • Too many re-renders. React limits the number of renders to prevent an infinite loop.A state setter is being called during render, which triggers another render, which calls it again. Usually it's an onClick that calls a function instead of passing one.
  • TS1259: Module can only be default-imported using the 'esModuleInterop' flagYou wrote a default import (import x from "pkg") for a CommonJS package whose types use export =. TypeScript only allows that when esModuleInterop (or allowSyntheticDefaultImports) is enabled.
  • TS1484: 'X' is a type and must be imported using a type-only import when 'verbatimModuleSyntax' is enabled.With verbatimModuleSyntax on, TypeScript keeps every import that isn't marked as type-only, so importing a type with a normal import would leave a runtime import of something that doesn't exist. Vite, Angular and SvelteKit templates enable this flag by default.
  • TS2307: Cannot find module or its corresponding type declarations.The TypeScript compiler can't resolve an import to a file or a type declaration. The package is missing, it ships no types, the file type isn't declared, or a path alias isn't configured.
  • TS2322: Type 'X' is not assignable to type 'Y'TypeScript found a value whose type doesn't fit the declared type of the variable, property, return value or prop it's assigned to. The indented lines under the error tell you exactly which part doesn't fit.
  • TS2345: Argument of type 'string | undefined' is not assignable to parameter of type 'string'.TypeScript found a function call whose argument type doesn't match the parameter type. Most often a possibly-undefined or possibly-null value is passed where a definite value is required, or a wide type (string) is passed where a narrow one (a union of literals) is expected.
  • TS2564: Property 'x' has no initializer and is not definitely assigned in the constructor.With strictPropertyInitialization (part of strict mode), TypeScript requires every non-optional class property to be assigned in its declaration or the constructor.
  • TS2769: No overload matches this call.The function you called has several overload signatures in its type definitions, and your arguments don't fit any of them. TypeScript shows why each overload failed; the useful detail is usually in the last or most specific one.
  • TS7016: Could not find a declaration file for moduleThe package is installed and its JavaScript was found, but it ships no TypeScript types and there is no @types package installed, so with noImplicitAny on TypeScript refuses to treat it as any.
  • TypeError: Cannot read properties of undefined (reading 'x')You accessed a property on a value that is undefined. The data isn't loaded yet, the object path is wrong, or a function returned nothing.
  • TypeError: Failed to fetchfetch() never got an HTTP response it was allowed to read. The usual causes are CORS, the server being down or unreachable, mixed content (HTTP from an HTTPS page), a wrong URL, or a browser extension blocking the request.
  • TypeError: x is not a functionYou called something with () that isn't a function, e.g. .map on an object instead of an array, a misspelled method, a wrong import, or a variable that shadows the function.
  • Warning: Can't perform a React state update on an unmounted component.An async task (fetch, timer, subscription) finished after its component was removed and then called setState. React 18 removed this warning, but the underlying bug (wasted work, race conditions) is still worth fixing with an effect cleanup.
