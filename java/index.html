Java errors

  • Could not resolve all dependencies for configurationGradle could not download or locate one or more dependencies for a configuration. The artifact or version does not exist in the declared repositories, the repository is missing, or the network/proxy/auth blocks access.
  • error: cannot find symbolThe Java compiler saw a name (class, variable or method) it can't resolve. Usually a typo, a missing import, a variable used outside its scope, or a dependency that isn't on the classpath.
  • error: class X is public, should be declared in a file named X.javaA public top-level class must live in a file with exactly the same name (case-sensitive) plus `.java`. The file name and the class name don't match.
  • Error: Could not find or load main classThe JVM couldn't find the class you asked it to run on the classpath. Usually you ran it from the wrong directory, used the file name instead of the fully qualified class name, or forgot the package folder.
  • Error: Could not find or load main class org.gradle.wrapper.GradleWrapperMainThe ./gradlew script can't find gradle/wrapper/gradle-wrapper.jar, usually because the jar was never committed (ignored by .gitignore), was deleted, or is corrupted, or the script is run from the wrong directory.
  • error: incompatible types: possible lossy conversion from double to intYou assigned a wider numeric type (double, float, long) to a narrower one (int, short, byte, char). Java won't silently drop the fraction or high bits, so you must cast or round explicitly, or use a wider variable type.
  • ERROR: JAVA_HOME is not set and no 'java' command could be found in your PATH.Gradle, Maven or another tool can't find a Java installation. Install a JDK and set JAVA_HOME to its folder.
  • error: missing return statementA method with a non-void return type has at least one path through it that reaches the end without returning a value or throwing. javac checks every path, including loops and if/else branches it cannot prove are exhaustive.
  • error: release version 17 not supportedThe javac doing the compile is older than the Java version the project targets (e.g. JDK 11 compiling with --release 17). Maven, Gradle or the IDE is using a different JDK than you think.
  • error: unreachable statementThe compiler proved that a statement can never execute, because it comes after `return`, `throw`, `break`, `continue`, or an infinite loop. Java treats this as a compile error, not a warning.
  • Exception in thread "main" java.lang.StackOverflowErrorA thread's call stack ran out of space, almost always because of infinite or very deep recursion: a missing base case, two methods calling each other, or toString/equals/hashCode/JSON serialization looping over a bidirectional relationship.
  • Execution failed for task ':compileJava'.Gradle's Java compile step failed. The line itself is generic; the real cause is printed above it (a javac error) or below it (a toolchain/JDK problem like invalid source release).
  • Failed to configure a DataSource: 'url' attribute is not specified and no embedded datasource could be configured.Spring Boot found spring-boot-starter-data-jpa or spring-boot-starter-jdbc on the classpath, so it tried to create a DataSource, but there is no spring.datasource.url and no embedded database. Add the connection settings, add H2, or disable DataSource auto-configuration.
  • Failed to convert value of type 'java.lang.String' to required typeSpring MVC couldn't convert a request parameter, path variable or header from its string form to the Java type of your controller parameter, for example "abc" or "undefined" to Long, or a date string in the wrong format to LocalDate. It returns 400 Bad Request.
  • Field required a bean of type that could not be found.Spring tried to inject a dependency but no bean of that type exists in the application context. Usually the class is outside the component-scan package, is missing a stereotype annotation, or its auto-configuration didn't activate.
  • java.lang.ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5Code accessed an array position that doesn't exist. Valid indexes run from 0 to length - 1, so index == length (an off-by-one loop) or a negative index throws this.
  • java.lang.ClassCastException: class X cannot be cast to class YA cast (explicit, or one inserted by generics) found an object of a different runtime type. Common sources are raw or unchecked collections, JSON deserialized into LinkedHashMap, and the same class loaded by two class loaders.
  • java.lang.ClassNotFoundException: com.mysql.cj.jdbc.DriverThe MySQL JDBC driver (Connector/J) isn't on the runtime classpath. It's missing from your build file, has the wrong scope, isn't packaged in the JAR/WAR, or isn't in the app server's lib folder.
  • java.lang.IllegalArgumentException: Comparison method violates its general contract!Your Comparator or compareTo is inconsistent (not transitive, not symmetric, or changes while sorting), and Java's TimSort detected it. Fix the comparison logic; the sort is not the bug.
  • java.lang.IllegalStateException: Failed to load ApplicationContextA Spring test could not start the application context. The real reason is never in this line: scroll to the last 'Caused by:' in the stack trace — usually a missing bean, a database that can't be reached, or a bad property.
  • java.lang.NoClassDefFoundErrorA class that was present when your code was compiled can't be loaded at runtime. Either the JAR containing it is missing from the runtime classpath, or the class exists but its static initializer failed earlier.
  • java.lang.NullPointerException: Cannot invoke "String.length()" because "<local1>" is nullCode dereferenced a reference that is null — called a method, read a field, indexed an array, unboxed a number or synchronized on it. Since Java 14, the message names exactly which expression was null.
  • java.lang.NumberFormatException: For input stringInteger.parseInt, Long.parseLong or Double.parseDouble got a string that isn't a valid number of that type: whitespace, an empty string, decimals for an int, thousands separators, or a value out of range.
  • java.lang.OutOfMemoryError: Java heap spaceThe JVM couldn't allocate an object because the heap is full even after garbage collection. Either the max heap (-Xmx) is too small for the workload, or the program holds on to too much data (a leak or loading everything into memory).
  • java.lang.reflect.InaccessibleObjectException: Unable to make field accessible: module java.base does not "opens java.lang" to unnamed moduleSince Java 16 (JEP 396) and Java 17 (JEP 403), the JDK's internal packages are strongly encapsulated, so reflection into private JDK members fails. An old library (Lombok, Gradle, Gson, Kryo, Mockito, Spring) or your own code is calling setAccessible on a JDK class.
  • java.lang.StringIndexOutOfBoundsException: String index out of rangeA String method got a position outside 0..length-1 (charAt) or 0..length (substring). Usually an off-by-one loop, a string shorter than expected, or indexOf returning -1.
  • java.lang.UnsupportedClassVersionError: has been compiled by a more recent version of the Java RuntimeThe code was compiled for a newer Java than the one running it. Run it with a newer JDK, or compile for the older version with --release.
  • java.net.ConnectException: Connection refusedThe target host answered, but nothing was listening on that port (the OS sent a TCP reset). The server isn't running, listens on a different port or interface, or you're connecting to the wrong host, often localhost inside Docker.
  • java.net.SocketTimeoutException: Read timed outThe TCP connection was established, but the server sent no data within the read (socket) timeout. The server is slow, stuck, or a proxy/firewall is swallowing the response. It differs from `connect timed out`, which means the connection was never opened.
  • java.util.ConcurrentModificationExceptionA collection was structurally modified (add/remove) while it was being iterated, so the iterator detected the change and failed fast. It happens in single-threaded code too — usually a remove() inside a for-each loop.
  • java.util.InputMismatchExceptionScanner.nextInt(), nextDouble() and similar found a token that isn't a valid number of that type, e.g. letters, a decimal for nextInt, or 3.5 when the locale expects 3,5.
  • java.util.NoSuchElementExceptionYou asked for the next element of something that has none left: Scanner input that is exhausted or closed, an Iterator past its end, Optional.get() on an empty Optional, or a list/queue method on an empty collection.
  • javax.net.ssl.SSLHandshakeException: PKIX path building failedJava could not build a trust chain from the server's TLS certificate to a CA in its truststore (cacerts). Usually a self-signed or corporate-proxy certificate, a missing intermediate, or an outdated JDK truststore.
  • MismatchedInputException: Cannot deserialize value of type from Array value (token JsonToken.START_ARRAY)Jackson found a JSON array `[...]` where your Java type expects a single object `{...}`. The mapping target must be a List/array, or the JSON must be unwrapped first. The reverse case reports `from Object value (token JsonToken.START_OBJECT)`.
  • org.hibernate.LazyInitializationException: could not initialize proxy - no SessionYou accessed a lazy-loaded association (a @OneToMany collection or a lazy @ManyToOne proxy) after the Hibernate Session / transaction that loaded the entity was closed, so Hibernate can no longer query it. Load the data while the session is open, or return a DTO.
  • Request method 'POST' is not supportedSpring found a handler for the URL but not for that HTTP method, so it returned 405 Method Not Allowed. The mapping uses a different method, the path doesn't match, or the request was redirected/forwarded (often by Spring Security or a form).
  • The operation couldn't be completed. Unable to locate a Java Runtime.On macOS, `/usr/bin/java` is only a stub that looks for a JDK in /Library/Java/JavaVirtualMachines. This message means none is registered there, e.g. Java is not installed or was installed by Homebrew without the symlink.
  • Unsupported class file major version 65A tool that reads .class files (Gradle's Groovy, ASM, an old Spring, Jacoco, Lombok, Spotbugs, Android Gradle Plugin) is older than the JDK that compiled those classes or that runs the build. Usually: Gradle is too old for your JDK.
  • Web server failed to start. Port 8080 was already in use.Spring Boot's embedded Tomcat (or Jetty/Undertow) couldn't bind to port 8080 because another process is already listening there — often a previous run of the same app that never stopped.
  • Whitelabel Error PageSpring Boot's default error view. It means a request failed (most often 404 because no controller handles the URL, or 500 from an exception) and you have no custom error page. The status line tells you which.
