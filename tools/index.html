Free developer tools

Small, fast tools for everyday debugging: formatters, converters and decoders. They run entirely in your browser, so nothing you paste ever leaves your machine. No sign-up, no ads.

  • JSON formatter & validatorPaste JSON to pretty-print or minify it; if it is invalid, the tool shows the error, its line and column, and highlights the exact character.
  • Cron expression explainerType a 5-field cron expression to see what it means in plain English and exactly when it will run next.
  • chmod calculatorTick the permissions you want, or type an octal or symbolic mode, and get the matching chmod command.
  • Unix timestamp converterPaste a Unix timestamp to see it as a UTC, ISO 8601 and local date, or type a date to get its timestamp; seconds and milliseconds are detected automatically.
  • Base64 encode / decodeEncode any text to Base64 or decode Base64 back to readable text, with correct UTF-8 handling and an optional URL-safe alphabet.
  • URL encode / decodePercent-encode or decode text for URLs, and paste any URL to see its query parameters decoded in a table.
  • JWT decoderPaste a JSON Web Token to read its header and payload and see whether it has expired; decoding happens locally and the signature is not verified.
  • Regex testerEnter a JavaScript regular expression and some text to highlight every match and inspect its capture groups as you type.
  • YAML validator & YAML ↔ JSON converterPaste YAML to validate it and convert it to JSON, or paste JSON to turn it into YAML. Errors show the line, the column and what is wrong.
  • UUID generator & validator (v4, v7)Generate up to 1000 UUIDs at once (random v4 or time-ordered v7), or paste a UUID to check that it is valid and see its version, variant and timestamp.
  • Text diff checkerPaste two versions of a text, config file or code snippet to see exactly which lines were added, removed or changed.
  • HTTP status codes referenceEvery standard HTTP status code plus the common non-standard ones from nginx, Cloudflare and Laravel, each with what it means and what usually causes it. Type a code or a word to filter.
  • Hash generator (MD5, SHA-256, SHA-512)Type text or pick a file to get its MD5, SHA-1, SHA-256, SHA-384 and SHA-512 hashes at once, then paste an expected checksum to verify a download.
  • Line ending & whitespace inspectorOpen a file or paste text to see its line endings, indentation, BOM and any invisible characters, then normalize it with one click.
