Rust errors

  • error: linker `cc` not foundrustc compiles your code itself but uses the system C toolchain to link the final binary. No C compiler/linker (cc) is installed, so linking fails. Install build-essential (Debian/Ubuntu), gcc (Fedora/Arch/Alpine) or Xcode Command Line Tools (macOS).
  • error[E0106]: missing lifetime specifierA function returns a reference, or a struct/enum holds one, and Rust can't infer which input the reference borrows from. You must name the lifetime — or return/store an owned value instead.
  • error[E0277]: the trait bound is not satisfiedYou used a type where a trait implementation is required (by a generic bound, a macro like println!, or the ? operator) but the type doesn't implement that trait. Derive or implement the trait, convert the value, or change the bound.
  • error[E0308]: mismatched typesAn expression has a different type than the place it's used requires. Rust never converts between types implicitly, so you must parse, convert, borrow, dereference or wrap the value explicitly.
  • error[E0382]: borrow of moved valueYou used a value after ownership moved somewhere else. Borrow it with & instead of moving it, clone it, or reorder the code.
  • error[E0412]: cannot find type `X` in this scopeThe compiler can't resolve a type name at that point: it isn't imported with `use`, is misspelled, lives in another module that isn't declared or public, is a generic parameter you forgot to declare, or needs a crate feature.
  • error[E0425]: cannot find value `x` in this scopeYou used a variable, constant or function name that doesn't exist where you used it: it is out of scope (declared inside a block), misspelled, not imported, or `self` is missing in a method.
  • error[E0433]: failed to resolve: use of undeclared crate or moduleThe compiler can't find the first segment of a path like foo::bar. Either the crate isn't in Cargo.toml, the module isn't declared with mod, or the name or path is spelled differently.
  • error[E0463]: can't find crate for `std`rustc could not find a crate it was told to link. For `std`/`core` the standard library for your target isn't installed; for other crates you're usually calling rustc directly or using `extern crate` without the dependency in Cargo.toml.
  • error[E0502]: cannot borrow as mutable because it is also borrowed as immutableYou tried to change a value while a reference to it is still in use. Finish using the reference first, copy the data out, or restructure the code.
  • error[E0515]: cannot return reference to local variableA function tries to return a reference to a value it created. That value is dropped when the function returns, so the reference would dangle. Return the owned value instead.
  • error[E0599]: no method named `x` found for struct `T` in the current scopeRust can't find a method with that name for the value's type. Usually the method comes from a trait that isn't imported, the type is wrapped (Option, Result, Rc, &), a trait bound is missing, or a crate feature is disabled.
  • error[E0603]: struct is privateYou're referring to an item (struct, function, module, enum, constant) from outside the module that defines it, but it isn't marked pub. Rust items are private to their module by default.
  • error[E0616]: field `x` of struct `Y` is privateStruct fields are private to the module that defines the struct by default. Code in another module (or crate) tried to read or write a field that isn't marked pub.
